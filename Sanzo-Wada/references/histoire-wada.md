# Repères sur Sanzo Wada

Seuls les faits présents dans la documentation du jeu de données amont ou dans la notice de l'éditeur sont repris ici.

- Sanzo Wada (1883-1967), artiste japonais (README amont).
- Édition de référence du jeu de données : *A Dictionary of Color Combinations*, Seigensha Art Publishing, 2010,
  ISBN 978-4-86152-247-5, 348 combinaisons (notice de l'éditeur).
- Original japonais : *Haishoku Sōkan*. Le README amont le date de 1933-1934 ; d'autres sources mentionnent 1918 pour de
  premières publications. **Dates non confirmées sur source primaire** : citer l'édition de 2010 quand une date est nécessaire.
- Contenu : 348 combinaisons de 2, 3 ou 4 couleurs, 159 couleurs uniques réparties en 6 chapitres de nuanciers.
- Chaque couleur du livre a un nom (par exemple « Burnt Sienna »), des valeurs CMYK et la liste des combinaisons où elle apparaît.
